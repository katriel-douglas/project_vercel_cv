# project_vercel_cv
// Project vercel CV

Este projeto consiste em uma versão digital e responsiva do meu currículo
profissional, desenvolvida para facilitar o acesso às minhas informações
profissionais através de um único endereço.

A aplicação reúne informações sobre minha trajetória profissional,
formação, competências técnicas, experiências e principais conhecimentos
em Tecnologia da Informação.

O projeto também faz parte do meu portfólio pessoal e demonstra meus
conhecimentos em desenvolvimento web, organização de informações,
responsividade e publicação de aplicações.

## 🎯 Objetivos

- Criar uma versão digital e acessível do meu currículo
- Facilitar o acesso às minhas informações profissionais
- Disponibilizar meu currículo através de um endereço público
- Criar uma apresentação profissional para processos seletivos
- Demonstrar conhecimentos em desenvolvimento web

## ✨ Características

- 📱 Design responsivo
- 💻 Compatibilidade com desktop, tablet e smartphone
- 🎨 Interface limpa e profissional
- ⚡ Carregamento rápido
- 🔗 Links para redes profissionais e portfólio
- 📄 Apresentação organizada das experiências e competências
- 🌐 Hospedagem através da Vercel

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- Vercel
